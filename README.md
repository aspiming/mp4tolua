# mp4tolua
视频转纯 Lua 像素动画工具

本项目用于将 MP4 视频转换为纯 Lua 数据表。主要针对**无法导入外部图片或视频资产的受限 UI 引擎**如千星奇域，通过纯代码生成控件来播放像素动画。

## 🐍 Python 端：数据生成工具

Python 端负责将视频画面解析、压缩并转换为 Lua 文件。

### 环境依赖
- Python 3 （用exe应该就不用）
- FFmpeg（需配置到系统环境变量，确保 CMD 能直接运行 `ffmpeg`）
1.	打开浏览器访问：https://www.ffmpeg.org/download.html
2.	点击 Windows 图标，选择 "Windows builds from gyan.dev"。
3.	在页面中找到 "release builds" 并下载 ffmpeg-release-essentials.zip。
4.	解压到一个固定文件夹（比如 D:\ffmpeg），进入里面的 bin 文件夹，复制当前路径（例如 D:\ffmpeg\bin）。
5.	在电脑底部的搜索框搜“环境变量”，打开系统环境变量设置，找到 Path，双击，点击“新建”，粘贴刚才的路径，一路确定。
6.	打开 CMD，输入 ffmpeg -version，看到版本号就代表安装成功。


### 实现原理
1. **视频抽帧**：调用 FFmpeg 提取指定分辨率、帧率的原始 RGB 二进制数据。
2. **颜色量化**：将 RGB 值按固定步长（如 16 或 24）取整，减少颜色种类，提升后续合并效率。
3. **2D 矩形合并**：扫描每帧像素，将横向和纵向连续的同色像素合并为一个大矩形。
4. **数据压缩**：将合并后的矩形信息 `(x, y, 宽, 高, 颜色索引)` 转为扁平的一维数组，生成极简格式的 `GridData.lua`。

### 使用方法
1. 运行 `Tool.py` 打开图形界面。
2. 选择视频文件，设置开始时间、时长、分辨率（如 192x108）、帧率（如 12）及取色方案。
3. 点击生成，得到 `GridData.lua` 文件（注意控制文件体积在平台限制内）。

## 🌙 Lua 端：运行时渲染

Lua 端在引擎运行时读取数据，并动态用方块拼出画面。

### 实现原理
1. **控件池**：根据数据中“单帧最大矩形数量”提前实例化对应数量的纯白图片控件。
2. **逐帧渲染**：在引擎的 `OnUpdate` 中，按帧率读取一维数组，动态修改控件的尺寸 (`Size`)、位置 (`Position`) 和颜色 (`Color`)。
3. **基础交互**：
   进度条：计算点击/拖拽的屏幕坐标百分比，跳转至对应帧。
   播放控制：暂停/继续，播放完毕自动定格或重播。

### 使用方法
1. 在引擎中准备好基础模板：光标检测区域、普通图片、纯白像素块图片、预设按钮。
2. 将 Python 端生成的 `GridData.lua` 作为脚本映射导入。
3. 将仓库中的 `Main.lua` 挂载到客户端控件容器上，填入对应的模板索引 ID 即可运行。
